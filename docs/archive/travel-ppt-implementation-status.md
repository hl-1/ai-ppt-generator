# 旅游规划 PPT 实施与验收记录

日期：2026-10-08

## 已实现

- 创建项目支持旅行条件提取、人工确认、日期、可接受时段、人员与年龄、预算和偏好；日期未定时生成建议草案。
- 接入和风天气 10 天预报、高德地点/住宿位置/路线以及 Firecrawl 官网检索与抓取；未配置、失败、部分完成和超时均有状态。
- 保存来源原文和版本；精确价格、时间与有效日期检查原文，按淡旺季日期选择规则，旧年份活动及公告不确认为本次安排。
- 按地理位置、旅行天数、游览强度、开放/停止入园时间及出返程缓冲编排行程；休息、冲突和缺失信息保留提示。
- 后端计算单价 × 数量 × 天数，分别展示官方规则、服务商参考报价、估算和缺价项目。
- 预约规则与用户预约状态独立保存；重新生成时读取用户当前状态。
- 大纲绑定查询版本，正文复用相同版本；修改条件或刷新资料后，旧大纲不能直接确认生成。
- 接入原有大纲确认、ARQ 队列、页面生成与 PPTX 导出。核心封面、条件、行程、预算及预约页由结构化资料生成，完整细节和来源进入讲稿。
- 前端提供查询进度、逐日路线与天气、住宿交通、费用明细、预约维护、来源和资料刷新；修复手机端表格撑宽页面的问题。
- 自动景点配图要求实景来源；未核对图片及缺图保留缺口，允许通过现有图库和上传流程补齐。

## 当前边界

- 酒店、机票和车票的实时库存、报价与预订需要供应商授权，尚未接入；高德提供位置及可取得的路线费用。
- 官网可访问不代表当年特殊日期安排已确认；一般规则仅作参考，出发前须刷新。
- 官网检索可能没有结果或超时；无法取得的票种、内部路线、季节活动、打卡点和替代场馆保持待核实。
- 已取得照片候选不代表已经人工核对，未核实的照片不会自动作为景点实景安装。
- 城际交通时长及实际班次未确认；首尾日 120 分钟缓冲明确为估算。
- 部分行程日没有可用景点时显示待补充，不用虚构景点填满日程。
